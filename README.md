# Legal Intake & Triage Assistant / 律师咨询分诊助手

Bilingual pre\-revenue legal\-tech prototype for law\-firm intake and triage\.

## Current version

- English\-first interface
- Chinese language toggle
- Mobile\-friendly PWA
- Intake form
- Priority scoring
- Missing\-information prompts
- Recommended next action
- Local\-only storage in the current demo
- No paid API required

## Privacy

The current demo does not upload case data to GitHub or a cloud database\. Records stay in the current browser’s localStorage\.

## Deployment

Static deployment works on GitHub Pages, Netlify or Cloudflare Pages\.

## Commercial handover

Current assets can be sold as a pre\-revenue prototype\. Authentication, cloud database, AI analysis, CRM integrations and maintenance can be scoped separately after acquisition\.
